Holafly Discount Code: Which Official Code Fits Your Plan?

Holafly's official discount page lists MYESIMNOW5 for 5% off a short-trip eSIM and MONTHLYPLAN10 for 10% off a monthly plan. Use the code that matches the product you select; Holafly says only one promo code can be applied per purchase.

Official source checked: 2026-09-24T00:01:11Z

How to apply a Holafly discount code

  1. Choose either a destination and days for a short trip, or a monthly plan subscription.
  2. At checkout, enter the matching code in Holafly's Discount code field and apply it.
  3. Complete the purchase after checking that the discount shown matches the code and product you selected.

What the official page says

Short trips: MYESIMNOW5

Holafly labels MYESIMNOW5 as 5% off for short trips and says it is valid for any destination available in the Holafly Shop.

Monthly plans: MONTHLYPLAN10

Holafly labels MONTHLYPLAN10 as 10% off for monthly plan subscriptions. Its official FAQ says this code applies to a monthly plan in the Plans section.

Can the two codes be combined?

No. Holafly's official FAQ says only one promo code can be applied per purchase. Pick the code that corresponds to the plan you are buying rather than trying to stack both.

Verify before you buy

Terms can change. Open the Holafly official discount-code page and recheck the code, plan and checkout total before paying.
