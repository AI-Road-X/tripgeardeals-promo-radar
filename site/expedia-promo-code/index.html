How to use an official Expedia coupon or member price

  1. Sign in to Expedia or use the Expedia app before searching if you want to check One Key Member Prices or app-only offers.
  2. On the official coupon page, check that the trip is eligible and choose Pay Now when the page presents that option.
  3. At payment, select “Enter a coupon or promotion code” on the website, or “Coupon Code” in the app, then enter only a code received through an eligible Expedia offer and select Apply.
  4. Review the final price, taxes, fees, hotel or package exclusions, blackout periods, minimum-stay rules, and availability before completing payment.

Expedia promo code FAQs

Does Expedia publish a current public promo code?

The official Expedia coupon page checked for this guide does not publicly display a current reusable code value. It explains how to redeem an eligible voucher and directs travelers to official deals when no code is available.

How do Expedia One Key Member Prices work?

Expedia says logged-in One Key members can receive 10% or more on select hotels, homes, and car rentals, with higher hotel savings available at some tiers. The price applies only where the Member Price banner appears and can change with the property and dates.

Is the Expedia student discount currently available?

No current student code was verified on the official Expedia pages checked for this guide. The student coupon page shows a past promotion, so its old code and dates are not presented as current.

Where do I enter an Expedia coupon code?

On the website, use “Enter a coupon or promotion” on the payment page. In the Expedia app, choose “Coupon Code” on the checkout page, enter the eligible code, and select Apply.
