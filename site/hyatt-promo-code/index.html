How to use an official Hyatt rate or offer

  1. Open Hyatt.com and choose the hotel, dates, room, and rate that match your trip.
  2. Sign in to World of Hyatt when checking member rates or member offers.
  3. Use Special Offer Code or Corporate or Group Code only when you have the applicable official offer or eligibility.
  4. Review property participation, availability, booking conditions, and any government, military, corporate, or group requirements before payment.

Hyatt promo code FAQs

Does Hyatt have one universal public promo code?

No universal reusable Hyatt code was verified on the official pages checked. Hyatt separates member rates, special offer codes, and qualification-based government, military, corporate, and group routes.

Where do I enter a Hyatt special offer code?

Hyatt's official booking flow provides a Special Offer Code field under Special Rates. Use a code only when its official offer terms apply to the selected booking.

Who can use Hyatt corporate codes?

A corporate code is for eligible company travelers using the applicable company or Hyatt Leverage route. It is not a general public code.

Can anyone use a Hyatt government rate?

No. Hyatt says its government rates are for eligible travelers on government-work-related business at participating U.S. hotels and resorts.
