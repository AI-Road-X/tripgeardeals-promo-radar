How to use an Airalo discount code

  1. Log in to your Airalo account on the website or in the app.
  2. Choose the eSIM you want and select Buy Now.
  3. At checkout, select Use Airmoney or code. On the website, select Code and enter the discount code before choosing Redeem.
  4. Use only one discount method for the order. If a code does not apply, check whether Airmoney or a referral code is already selected.

Airalo discount code FAQs

Where do I enter an Airalo promo code?

On the Airalo website, go to checkout, choose Use Airmoney or code, select Code, enter the code, and choose Redeem. In the app, use the same checkout area and tap Apply after entering the code.

Can I combine an Airalo promo code with a referral code or Airmoney?

No. Airalo says only one discount method can be used for each purchase: a discount or referral code, or Airmoney.

Who can use Airalo promo codes?

Airalo says most discount and promo codes are for new users who have not made an eSIM purchase, while some can apply to all users and purchases. Check the official discounts page for the current offer terms.
