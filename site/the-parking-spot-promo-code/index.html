How to use a The Parking Spot promo code

  1. In the app, open Reserve Your Spot. The official support page says app promo codes require a Spot Club membership.
  2. Select the airport and your check-in date and time, then enter the promo code on that screen.
  3. Continue to choose the facility and parking type.
  4. Open My Discounts to see which offers are being considered before completing the reservation.

If a promo code does not apply

Check whether another discount is already better

The official support page says discounts cannot be combined. If a better eligible discount is already applied, a promo code will not be accepted.

Confirm the reservation type and location

The official support page says discounts do not apply to Basic parking reservations or partner locations. Recheck the selected facility and parking type before booking.
